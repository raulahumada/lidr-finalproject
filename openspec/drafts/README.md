# OpenSpec drafts (pre-propose)

Borradores de `/opsx-prespec`. No son un change de OpenSpec hasta que el usuario aprueba y se corre Phase B (propose).

Cada archivo: `<change-name>.md`.

**Versionado:** esta carpeta está en `.gitignore` (salvo este README). Los drafts viven solo en tu máquina; no los incluyas en commits ni PRs. El trabajo formal va a `openspec/changes/` tras el approve.
